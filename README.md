# Hana 知识库

为 Hana 提供本地知识库能力的插件：把文件丢进库，对话中自然提问，相关内容被找出并附带出处。

## 版本

1.0.0

## 功能

- 多知识库：每个库一个独立 SQLite 文件，可备份、可搬走
- 入库：文件或整个文件夹，支持断点续跑、同内容跳过、内容变更自动重入
- 检索：向量检索（bge-m3）+ 可选 BM25 融合 + 可选图谱追加，结果带文档名、标题路径、原文偏移量
- 图谱：LLM 抽取实体关系，全景力导向图（拖动/缩放/悬停高亮）+ 局部连线视角，顺着关系链连续跳转
- 多样性重排（实验验证的开关）：库里长文档占比高时，开启可让多主题问题召回更全面；开关旁自动提示是否建议开启
- 管理界面：库列表、文件管理、召回测试、图谱浏览、参数设置
- 对话工具：建库、入库、检索、图谱等 12 个工具，Agent 可直接调用

## 支持格式

- Markdown（.md）、纯文本（.txt，自动识别 GBK/UTF-8 编码）
- Word/Excel/PDF 已列入 1.1 路线图，当前版本不支持

## 安装

1. Hana 设置 → 插件 → 本地安装，选择 `hana-kb-v1.0.0.zip`
2. 启用插件
3. 打开插件页 → 左侧「全局设置」→ 填写 embedding 服务（推荐硅基流动 `BAAI/bge-m3`）；图谱功能需要再填 LLM 配置（推荐 `deepseek-v4-flash`，注意该模型需服务商支持，硅基流动上可用 `deepseek-ai/DeepSeek-V3`）
4. 新建知识库 → 添加数据源 → 开始使用

## 每库参数

- 检索返回条数 topK（默认 15）
- 相似度阈值（默认 0.3，相似度口径）
- 分段大小 / 重叠（默认 400 / 50，修改后需重建索引生效）
- 图谱开关、BM25 开关、多样性重排开关

## 已知边界

- BM25 融合默认关闭：实现完整但收益验证未完成，开启前建议用你自己的问题实测
- 费用熔断未实现：入库前没有 token 费用预估，大批量入库前请留意 API 用量
- 图谱构建需调用 LLM：千段规模的库约数元成本、十几分钟耗时，后台执行不阻塞使用

## 数据与隐私

- 文档文本会发送给你配置的 embedding/LLM 服务商（用于计算语义指纹和抽取关系）
- 不想数据出本机，可配置本地 Ollama（网络白名单已包含 127.0.0.1）
- API 密钥仅保存在本机插件数据目录，不随插件分发
